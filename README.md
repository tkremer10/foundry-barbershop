# The Foundry Barbershop — Portfolio Demo

A responsive, single-file barbershop website for a **fictional** business. All prices, hours, services, and business details are illustrative. External Unsplash images are used for demonstration and should be replaced with properly licensed client photography before commercial delivery.

## GitHub Pages
1. Create a public repository named `foundry-barbershop`.
2. Upload `index.html` to the repository root.
3. In Settings → Pages, choose Deploy from a branch → `main` → `/ (root)` and save.
4. Visit `https://YOUR-USERNAME.github.io/foundry-barbershop/` after deployment completes.

## Before client launch
Replace fictional branding, copy, services, prices, opening hours and photography. Connect the booking button to a real scheduling URL. Add accurate business contact details and privacy/legal information as appropriate.
